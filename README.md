# Le Monde Suites

Apartment stays platform built with Next.js — public booking, admin calendar, and superadmin oversight.

## Features

### Guest portal
- Browse available suites and apartments
- Request a stay with date selection
- Responsive design for desktop and mobile

### Admin dashboard
- Apartment inventory management
- Reservation calendar and order table
- Confirm bookings (admin & superadmin)
- User authentication via NextAuth

## Tech stack
- **Frontend:** Next.js, React, MUI
- **Backend:** Next.js API routes
- **Database:** MongoDB
- **Authentication:** NextAuth.js
- **Deployment:** Vercel

## Dev

```bash
npm install
npm run dev
```

Runs on port `3026`.
